# DesktopCraft — Windows desktop organizer

DesktopCraft is a Windows desktop organizer written in Rust. It arranges icons into moveable, resizable boxes and pages. **This 0.1.0 public release line is derived from the earlier 0.1.11 source snapshot, with a responsiveness refactor and opt-in GitHub auto-updates.** See [Release build and updating](RELEASE_BUILD.md). DesktopCraft is the chosen product name; trademark clearance is still recommended before broad public distribution.

## Features

- Desktop boxes, per-monitor layouts, page switching and a hover page selector on the Windows primary display.
- Drag/drop, box type-ahead selection (Latin/Thai), icon sizing, explicit sorting rules, roll-up, snap-to-edge and equal-gap alignment.
- **Regular boxes are virtual groups**, not directories. Dragging icons between regular boxes, from Desktop/Explorer into a regular box, or from a regular box back to the Desktop changes only their icon placement/pin. The original disk file stays at its original path.
- **Folder View is different:** a box explicitly linked to an existing folder mirrors that folder. Dropping a file into this Folder View performs a real Windows Shell file move into the linked folder. Dragging a file out of Folder View onto Desktop performs a real move out. Name collisions are rejected without overwriting.
- The box ellipsis menu offers **Bind folder path** on a regular box, or **Change linked folder path** and **Open linked folder** on a linked Folder View. An occupied regular box must have its virtual pins moved/unpinned before binding so no pins disappear silently. Other unavailable box actions are omitted instead of greyed out.
- Settings has a separate **Paths & pins** page: select a regular destination box, pin a file by existing path, browse linked paths, and Unpin/Unlink without modifying disk contents. Help has no path-edit controls.
- The **Organize & rules** page separates Apply/Organize actions, rule pagination and counts; long labels are truncated so controls do not overlap. Each rule has an **Edit** button that opens it in its own pop-up window, like renaming a box. The window has the match type, the destination, and a large text box that wraps the whole rule, so long extension lists stay readable. **Save** keeps the rule in the same place in the list with the same on/off state, so its priority doesn't change; **Cancel** or Escape goes back to the rules page.
- DesktopCraft-managed file pins use a **DesktopCraft-drawn Windows 11-style file-actions menu** (not the actual modern Explorer menu), with **Show more options** opening Windows' native classic IContextMenu. A per-user installation additionally registers **Pin to DesktopCraft** in the Windows 11 classic menu; this changes only the virtual pin. Explorer-owned icons outside DesktopCraft regions retain their own genuine Windows 11 context menu.
- Page navigation stops at existing-page boundaries. Only the bottom + or Settings > Pages > + New page opens a confirmation dialog to create and name a page. Settings > Pages allows renaming any page without moving its boxes; empty pages may be deleted safely. Page edge-drags, middle-mouse page-swipes and Alt+wheel switching have been removed. Ctrl/Alt + Left/Right remains as the keyboard navigation shortcut, and desktop-mode polling is restricted to DesktopCraft/Windows desktop foreground.
- Peek no longer captures the Windows language switcher Win+Space. Settings > Peek provides an editable shortcut (e.g. Ctrl+Shift+P or Ctrl+Alt+G), validates it, and offers Reset default; unsafe/unmodified/Windows-key combinations are not accepted.
- Organize & rules uses actual dropdowns for rule match mode, destination Box and each rule's Enabled/Disabled state instead of cycling through hidden choices. The Exit DesktopCraft action is in Help, not Behavior.
- Dragging an ungrouped Desktop icon uses temporary Win32 mouse capture so mouse-up is received even beyond DesktopCraft's transparent window region. On drop, the icon snaps to the nearest available Explorer-size grid cell without overlapping another loose icon or visible box. DesktopCraft preserves Windows' own **Align icons to grid** setting; it no longer switches that setting off during ordinary Explorer updates.
- Dropping a DesktopCraft-managed icon onto the actual drawn **Recycle Bin** namespace icon calls Windows Shell's recycle operation with undo support and a warning if permanent deletion would otherwise be required. Ordinary non-bin drops and regular-box transfers do not delete/move file bytes. Recycle Bin drops are user-initiated disk operations, not reversible by DesktopCraft layout undo; Windows may offer restore.
- **Moving a box by its "…" button:** press and hold "…", then drag, to move the box. This always works, even when tabs fill the whole title bar. A plain click still opens the box menu (when you let go). Locked boxes don't move; their "…" just opens the menu.
- **Folder View tools:** the folder bar has a **filter** (magnifier) and a **sort** button beside the open-folder link. Click the magnifier and type part of a name, or an extension such as `.exe`, to show only matching files. Enter keeps the filter, Escape or a second click on the magnifier clears it, and it isn't saved. Sort opens a list: Name, File type, Date (newest) or Size (largest).
- **Menus close like Windows menus:** the "…" menu and the folder sort list close when you click anywhere else in Windows (another app, the taskbar, the empty desktop), not only on another box. A click elsewhere also stops typing into a folder filter.
- Floating Settings is drawn and dragged in the full virtual desktop coordinate space, so it can cross the primary monitor boundary onto another connected monitor. Mixed-DPI monitor setups still require live testing.
